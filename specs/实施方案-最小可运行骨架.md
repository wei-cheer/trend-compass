## 1. 一页结论

**做什么**：从零搭起一个**独立命名、独立结构**的工程 `trend-compass`（中文“热点罗盘”），**从 Step 0 就接入 Git 和 GitHub**：先建远端仓库并做初始提交，再搭后端探针接口和前端页面，每个 Step 一个 commit。

**不做什么**：
- 不沿用成品仓库的项目名、目录名、接口名
- 不接任何信息源（Twitter / Bing / B 站等）
- 不接 OpenRouter、不调用大模型
- 不做关键词增删改查、不做数据库表、不做定时任务
- 不做 WebSocket 推送、不封装 Agent Skills

**怎样算成功**：
- GitHub 上出现 `strange331/trend-compass` 仓库，本地 `git remote -v` 指向它
- 后端 `npm run dev` 启动在 3001 端口，`curl http://localhost:3001/api/probe/status` 返回 `{"state":"online","checkedAt":"..."}`
- 前端 `npm run dev` 启动在 5173 端口，页面显示标题“热点罗盘”和“探针状态：online”
- 每个 Step 都有一条独立 commit，`git status` 干净

## 3. 契约与口径

**接口**
| 方法 | 路径 | 入参 | 出参 | 错误码 |
| --- | --- | --- | --- | --- |
| GET | `/api/probe/status` | 无 | `200 {"state":"online","checkedAt":"<ISO时间>"}` | 无（本切片简化） |

**口径**
- 后端端口：`3001`；前端端口：`5173`（通用端口约定，非沿用项目命名）
- 技术栈：后端 Express 5（要求 Node.js 18+）；前端 Vite + React + TypeScript（Vite 要求 Node.js 20.19+ / 22.12+）
- 运行时：本机 Node v22.22.2，实测满足 Vite 下限，换机器前先 `node -v` 核对
- 依赖版本：不写死小版本，实际版本以 `api/package-lock.json` 为准
- 时间字段：`new Date().toISOString()`，例如 `2026-11-24T02:22:00.000Z`
- CORS：后端允许来源 `http://localhost:5173`
- Git 分支：`main`；每个 Step 一条 commit，提交信息见第 4 节
- 密钥：`.env` 必须进 `.gitignore`，只提交 `.env.example`
- **基准值**：`curl http://localhost:3001/api/probe/status` 必须包含 `"state":"online"`

**字段易错点**：
- 返回字段叫 `state`，不是 `status`；别写串
- 前端 fetch 要写完整 `http://localhost:3001/api/probe/status`，不要写相对路径（Vite dev 不会代理到 3001）
