## 1. 需求解析（SOP Step 1）

skill 脚本按关键词匹配出「首页/列表/设置」，但本项目当前只有单页状态展示，列表和设置页**本次不做**。按项目实际修正如下：

| 字段 | 值 |
| --- | --- |
| `project_type` | 工具 / 热点聚合平台（骨架期） |
| `target_platform` | Web（桌面优先，响应式兼容移动） |
| `user_persona` | 率土之滨游戏博主：要快速扫一眼看系统状态，调性沉稳、像作战沙盘 |
| `core_tasks` | ① 看探针是否在线 ② 一眼识别"不可达"故障态 |
| `brand_tone` | 传统 / 复古 / 沉稳（水墨、三国、作战沙盘） |
| `constraints` | 纯 CSS 零新依赖；不装 Aceternity UI/Tailwind；保留现有探针 fetch 逻辑与字段名 `state`；WCAG AA 正文对比 ≥4.5:1 |

### 2.5 ⚠️ 对比度校验（skill 不做，我手工验算——写代码前必看）

| 前景 / 背景 | 比值 | 判定 | 用法约束 |
| --- | --- | --- | --- |
| 宣纸白 `#EDE4D3` / 墨黑底 | **14.66:1** | AA 通过 | 正文主色，随便用 |
| 旧宣纸 `#A99B84` / 墨黑底 | **6.79:1** | AA 通过 | 次要文字可用 |

## 3. 组件规格卡（SOP Step 3）

本次页面只涉及 3 个组件（skill 规划了 4 类通用组件，按实际收敛）：

### 3.1 BrandTitle（品牌标题区）

| 属性 | 规格 |
| --- | --- |
| 结构 | `<h1>` 主标题 "热点罗盘" + 一行小字副标题（如"多源热点聚合 · 作战沙盘"） |
| 字号 | 主标题 `--fs-h1` 24px / `font-weight:700` / 字间距 `0.08em`（宋体拉开更稳） |
| 颜色 | 主标题用 `--gold` 烫金；副标题用 `--paper-dim` |
| 装饰 | 主标题左侧一道朱砂竖线（`border-left: 3px solid var(--cinnabar)`），呼应印章 |
| 状态 | 静态，无交互态 |
| 无障碍 | 标题语义用 `<h1>`，副标题用 `<p>`，不靠颜色单独传达含义 |

### 3.2 ProbeStatusCard（探针状态卡）— 核心组件

| 属性 | 默认态 | 加载态 | 在线态 | 不可达态 |
| --- | --- | --- | --- | --- |
| 边框 | `1px solid --ink-line` | 同默认 | `1px solid --celadon` | `1px solid --cinnabar` |
| 背景 | `--ink-surface` | 同默认 | 同默认 | 同默认 |
| 状态点 | `--paper-dim` 空心 | `--warn` 脉冲动画 | `--celadon` 实心 | `--cinnabar` 实心 |
| 状态文字 | "探针状态：待检测" `--paper-dim` | "探针状态：加载中" `--warn` | "探针状态：online" `--celadon` | "探针不可达" `--cinnabar` 18px 大字 |
| 字号 | `--fs-body` 16px | 16px | 16px，值 "online" 用 `--fs-h3` 18px | 18px |
| 阴影 | `--shadow-card` | 同默认 | 同默认 | 同默认 |
| 尺寸 | `padding: --space-6`(24px)；最小高 96px | 同 | 同 | 同 |

> 文字取值必须沿用现有 `probe` 三态（`loading`/`online`/`unreachable`），**不要改 state 判定逻辑**，只换样式与呈现。

### 3.3 加载动画（ pulses，纯 CSS）

| 属性 | 规格 |
| --- | --- |
| 实现 | `@keyframes` 改状态点 `opacity: 1 → 0.35 → 1`，`1.2s ease-in-out infinite` |
| 降级 |  `@media (prefers-reduced-motion: reduce)` 下取消动画，静态显示 |
| 依赖 | 无（不用任何动画库） |

## 4. 页面布局蓝图（SOP Step 4）

当前页面内容少，布局保持单列居中（作战沙盘感：内容收拢、留白多、不铺满）。

```
┌─────────────────────────────┐
│  ▌热点罗盘            ← 品牌区（朱砂竖线 + 烫金标题）
│    多源热点聚合 · 作战沙盘   ← 副标题（旧宣纸小字）
│                             │
│  ┌───────────────────────┐  │
│  │  ●  探针状态：online   │  │  ← 状态卡（青瓷边 + 状态点）
│  └───────────────────────┘  │
│                             │
│   （下方留白，后续放数据区）  │
└─────────────────────────────┘
```

| 区块 | 容器 | 布局要点 |
| --- | --- | --- |
| 页面容器 | `<main class="compass">` | `max-width: 720px; margin: 0 auto; padding: --space-12 --space-8` |
| 品牌区 | `<header class="compass__header">` | `margin-bottom: --space-8` |
| 状态卡 | `<section class="probe-card">` | 单列，状态点与文字用 flex 同行 |
| 数据区 | 暂无 | 预留，本次不建 |

**响应式断点**（skill 脚本输出，保留）：

| 断点 | 布局策略 |
| --- | --- |
| ≤375px | 单列；容器内边距降到 `--space-4` |
| ≤768px | 单列（内容本就少，无需双列） |
| ≤1024px | 单列居中，最大宽 720px |
| >1440px | 仍单列居中，避免状态卡被拉得过宽 |

**关键路径**：打开页面 → 看品牌标题确认是"热点罗盘" → 看状态卡颜色/文字判断探针通断。

### 5.2 类名命名（BEM 风格）

| 块 | 元素/修饰 | 说明 |
| --- | --- | --- |
| `.compass` | `__header` `__title` `__subtitle` | 页面与品牌区 |

| `.probe-card__dot` | （配合修饰类变色） | 状态点 |

### 5.3 与现有代码的对齐点（代码 AI 必读）

| 现有代码 | 改动方式 |
| --- | --- |
| `PROBE_URL` 常量 | **不动**，仍是 `http://localhost:3001/api/probe/status` |
| `useEffect` + `fetch` + `cancelled` 防竞态 | **不动** |
| `data.state === 'online' ? 'online' : 'unreachable'` 判定 | **不动** |
| `<h1>热点罗盘</h1>` | 保留文字，加 class 与装饰 |

### 5.4 无障碍要点
