# trend-compass（热点罗盘）

面向自媒体创作者的**多源热点聚合平台**。当前处于骨架搭建阶段。

## 定位

把多个信息来源的热点聚合到一处，供内容创作者筛选、追踪并产出视频与图文内容。项目名、目录结构与接口命名均为独立设计，不沿用参考项目。
